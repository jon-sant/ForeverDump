1. TL;DR and mental model top

  • A secret is an opaque box around a normal Lua value. Your addon (tainted code) can hold it, pass it to Blizzard APIs and widgets, and display it, but cannot look inside or compute with it: arithmetic, ordered comparison, #, table keys and string parsing fail Official (Blizzard): B-251001 Docs / datamined: W-SV.
  • Forever runs the Midnight (12.x) system: Blizzard says Forever shares Mainline's UI architecture and 'the vast majority of APIs available in 12.1.5', and 'the addon disarmament changes introduced in Midnight, including secrets, will also be active in Forever' Official (Blizzard): WH-FOREVER.
  • On Forever 70245 UnitHealth('player') is secret even out of combat (alive and dead) while UnitHealthMax('player') is a plain number (1345 in the user's test) Verified in-game: USER-TEST, SV-RUN2. Guides saying 'out of combat everything is readable' are wrong for this build Community: C-DEVGUIDE.
  • Many values are conditionally secret: cooldown timing, auras, unit stats (incl. movement speed), threat, damage-meter sessions turn secret when the Combat restriction (or Encounter / M+ / PvP / Map) is active Docs / datamined: INV Verified in-game: SV-RUN2.
  • Unit tokens (party1, target, nameplate3...) still resolve; secrecy attaches to the values returned for a unit, not to the token. Some APIs refuse certain token kinds (compound boss1target, names, nameplate/party mixes) Official (Blizzard): B-260121, B-260325 Docs / datamined: DOCS. See Unit tokens.
  • Rule of thumb: display, don't decide. Feed secrets into widgets, use engine-side helpers (UnitHealthPercent + curves, duration objects, AuraContainer), use non-secret neighbours, and drop logic that needs the real number in combat; that is the stated intent Official (Blizzard): B-251113 Inference.

9. Hybrid state machine (HSM) top

A hybrid state machine keeps two layers per unit: observed facts from readable inputs and inferred predictions from rules over those inputs and knowledge cached while things were readable. Anything else is unknown. When later readable evidence disagrees with a prediction, it records a contradiction and the rule loses confidence. ForeverDump v2.2 ships one (Lib/HybridState.lua, Inference.lua, Knowledge.lua) plus a live window Community: FD.

The in-game HSM window

  • Open it: /fdump hsm toggles the window. Turning the FD_Logs capture ON opens it automatically (setting hsm.autoShow, default true) and OFF closes it. If no capture is running the window says 'HSM not running'; /fdump hsm start starts the HSM without a capture Community: FD.
  • Window: a plain insecure frame (no secure templates, no hooks on Blizzard frames); drag to move, corner grip to resize, Escape closes; position/size saved in ForeverDumpDB.hsmUI; refreshed every 0.2 s (hsm.updateInterval) only while shown Community: FD.
  • Colours: green = observed (read from a non-secret value or event), yellow = inferred (rule output; the rule and confidence are printed next to it), grey = unknown / cached / unverified, red = contradiction. The restriction line reuses the palette: green Inactive, yellow Activating, red Active Community: FD.
  • Engine passthrough rows: secret values are shown only through sanctioned widgets so you can compare by eye: 'player/target cast (secret, engine)' bars driven by StatusBar:SetTimerDuration(UnitCastingDuration(unit)) (or UnitChannelDuration), 'player/target HP (secret, engine)' bars via SetMinMaxValues(0, UnitHealthMax) + SetValue(UnitHealth), a 'real cooldown' Cooldown frame via SetCooldownFromDurationObject(C_Spell.GetSpellCooldownDuration(id)), and an HP FontString via SetText. The addon never reads these back (no GetValue/GetText) Community: FD Docs / datamined: DOCS.
  • Text body: restriction states for all six types plus the always-on flags (combat log, addon chat); counters (predictions, inferences, contradictions, unreadable inputs, casts, aura events); player/target cast state; known/predicted auras per unit (source, rule, confidence, stacks, remaining); cooldown predictions; the last 8 predictions with outcome (green verified, red contradicted, grey unverified); the last 4 contradictions with how early and which rule Community: FD.

How to verify predictions with it

  1. Pair the bars. Each yellow 'pred' bar sits above its white engine bar. Cast a spell with a known cast time: both should fill together and end together. A yellow bar that ends early or late shows the error of your cast-time knowledge (haste, pushback).
  2. Watch a cooldown. Cast a spell with a static cooldown, then compare 'cooldown (pred)' with the real Cooldown swipe on the right. They should finish within a GCD. Persistent drift = wrong base cooldown or a modRate you didn't learn.
  3. Check aura rows. Buff yourself in combat. The aura should appear yellow (inferred via the cast-aura window rule) and turn green after combat when the readable data confirms it. A red line means it vanished more than the tolerance (1.5 s) before the predicted end.
  4. Read the counters. After a fight: contradictions should be near 0; 'unreadable inputs' tells you how much the HSM had to guess. A high number with zero predictions means the rules lacked knowledge: run /fdump out of combat first so Knowledge.lua caches durations.
  5. Score offline. Turn FD_Logs OFF (saves via /reload). The converter step (tools/fdump.py, HSM scoring in progress) replays every logged prediction against the WoWCombatLog file and writes the --hsm JSON this guide renders under Verified vs pending. Until then every rule shows as pending.
  6. Repeat per context. Do a dummy (Combat only), a dungeon (Map + Encounter) and, if possible, a battleground (PvPMatch): readability of rule inputs is logged per context, so the same prediction can be verified in one and pending in another.

Lua skeleton

-- Minimal HSM skeleton (readable inputs only). Full version: ForeverDump/Lib/HybridState.lua
local HSM = { units = {}, know = {}, preds = {}, window = 0.6, tolerance = 1.5 }
local f = CreateFrame("Frame")

local function key(unit)                                    -- GUID while readable, else token
  local g = UnitGUID(unit)
  if g ~= nil and not issecretvalue(g) then return g end
  return unit
end

function HSM:Learn(id)                                      -- call out of combat
  if C_Secrets.ShouldAurasBeSecret() then return end
  local a = C_UnitAuras.GetPlayerAuraBySpellID(id)
  if a and not issecretvalue(a.duration) then self.know[id] = { duration = a.duration } end
end

function HSM:OnCast(unit, id)
  if unit ~= "player" or issecretvalue(id) then return end  -- observed
  self.last = { id = id, t = GetTime() }
end

function HSM:OnAura(unit, info)
  local u = self.units[key(unit)] or {}; self.units[key(unit)] = u
  if not C_Secrets.ShouldAurasBeSecret() and info and not info.isFullUpdate then
    for _, a in ipairs(info.addedAuras or {}) do               -- readable: observed
      u[a.auraInstanceID] = { spell = a.spellId, ends = a.expirationTime, state = "observed" }
    end
    return
  end
  local L = self.last                                           -- secret: infer
  if L and GetTime() - L.t <= self.window and self.know[L.id] then
    local p = { unit = key(unit), spell = L.id, ends = GetTime() + self.know[L.id].duration,
                state = "inferred", rule = "cast-aura-window" }
    table.insert(self.preds, p)
  end
end

function HSM:Verify(unit, id, endedAt)                         -- later readable evidence
  for _, p in ipairs(self.preds) do
    if p.unit == key(unit) and p.spell == id and p.state == "inferred" then
      p.state = (p.ends - endedAt > self.tolerance) and "contradicted" or "verified"
    end
  end
end

f:RegisterUnitEvent("UNIT_SPELLCAST_SUCCEEDED", "player")
f:RegisterUnitEvent("UNIT_AURA", "player", "target")
f:SetScript("OnEvent", function(_, ev, unit, a2, a3)
  if ev == "UNIT_SPELLCAST_SUCCEEDED" then HSM:OnCast(unit, a3) else HSM:OnAura(unit, a2) end
end)

  bar:SetMinMaxValues(0, v)            -- display path

Pitfalls

  • Testing if x then on a value you think is secret: it is a nil test and passes; the error only appears later when you compare or add Official (Blizzard): B-251104.
  • issecretvalue(tbl) is false for struct tables and duration objects; check the fields or HasSecretValues() Docs / datamined: DOCS Verified in-game: SV-RUN2.
  • Treating 'nil' as 'clear': UnitGetIncomingHeals, UnitCastingInfo and GetRaidTargetIndex return nil when there is nothing, so a nil sample proves nothing about secrecy Verified in-game: SV-RUN2 Docs / datamined: RESEARCH.
  • Waiting for ADDON_RESTRICTION_STATE_CHANGED with state 2: it is never sent; poll on the next frame Docs / datamined: DOCS Verified in-game: SV-RUN2.
  • Copying retail whitelists (Hearthstone, raid buffs) to Forever: 70245 reported them ContextuallySecret Verified in-game: SV-RUN2.
  • tostring(secret) looks like it works (prints fine) but the string is secret; tonumber of it is nil Verified in-game: USER-TEST.
  • Hard-coding WOW_PROJECT_ID == 1 from Forever beta notes Community: C-KIT vs 18 on 70245 Verified in-game: SV-RUN2.
  • Registering COMBAT_LOG_EVENT_UNFILTERED: restricted (HasRestrictions) Docs / datamined: INV; project notes report an ADDON_ACTION_FORBIDDEN popup Community: FD Pending lab.
  • Assuming the error names the real culprit: taint errors blame the addon that tainted the path, which may be a library or a different addon Community: C-DECURSIVE.

  1. Inventory. List every API/event your addon calls; join it with the inventory TSV (SecretReturns / SecretWhen* / NeverSecret / Requires*) Docs / datamined: INV.
  2. Classify. For each value: display-only, logic-needed-ooc, logic-needed-in-combat. The last group needs a non-secret neighbour, an engine helper, or removal Inference.
  3. Guard. Add issecretvalue / HasSecretValues checks before any arithmetic, comparison, table key, #, string parsing Docs / datamined: DOCS.
  4. Widgets. Move displays to passthrough: StatusBar SetValue, FontString SetText, SetTimerDuration, SetCooldownFromDurationObject, curves, AuraContainer Docs / datamined: DOCS Official (Blizzard): B-260618.
  5. Events. Re-check every event payload (UNIT_AURA, UNIT_SPELLCAST_*, threat, range) for SecretPayloads / SecretWhen* Docs / datamined: INV.
  6. Tokens. Replace compound tokens and names in aura/nameplate calls; gate UnitIsUnit with CanCompareUnitTokens Official (Blizzard): B-260121, B-260331.
  7. Taint. Remove writes into Blizzard tables/globals; use hooksecurefunc; switch to GameTooltip_AddMoneyLine Official (Blizzard): B-260430; turn on /console taintLog 1 while testing Docs / datamined: RESEARCH.
  8. SavedVariables. Never save secrets; save classifications Official (Blizzard): B-251111.
  9. Combat log. Drop CLEU parsing; use C_DamageMeter, UNIT_* events, or post-combat summaries Docs / datamined: INV Official (Blizzard): B-250603.
