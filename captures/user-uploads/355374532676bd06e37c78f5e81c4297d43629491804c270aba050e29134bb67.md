## How to read

- Contexts: **ooc** = out of combat (open world), **combat** = PvE combat, **pvp** = inside a battleground (PvP-restricted, between fights included, and PvP combat; run 8 only so far).
- Readability: `clear` readable value (C); `secret` secret value (S/T); `error` API errors / refused (E); `mixed` clear and secret both seen; `guarded` skipped by CombatGuard (G); `nil` only nil returned; `-` not measured. Counts after the verdict are raw code counts (C clear, S secret, E error, N nil, G guarded).
- HSM status: `live` readable live in combat; `cached` read out of combat, carried into combat; `correlated-proven` HSM inference scored >= 95% on >= 10 events over >= 2 runs; `provisional` HSM inference with too little evidence (or one run); `estimated` HSM estimate (approximate value); `unsolved` secret/error in combat and no proven inference; `not measured` no capture covered it.
- Evidence sources: `tokens:` token scanner matrix, `probe:` combat probe cells, `ring:` recorder events (SC_ = UNIT_SPELLCAST_, .N = argument N), `containers:` aura/struct schema, `HSM` pooled rule accuracy vs the combat log, `FINDINGS` curated claim (used only while the quoted sentence is in that run's FINDINGS.md).
- Cumulative SV stores are merged per cell from the newest run holding it; recorder sessions count once.
